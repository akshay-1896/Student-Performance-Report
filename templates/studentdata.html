About This Project

Project Overview:

This is an end-to-end Machine Learning application for predicting student academic performance. Built with MLOps best practices, it uses a Random Forest Classifier to predict whether a student will PASS or FAIL based on various lifestyle and academic factors. The application features interactive web interface, prediction history tracking, and cloud integration.
